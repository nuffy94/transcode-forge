Storage — how the worker reads & writes media

Filesystem libraries

Mount the media path read-write:

-v /mnt/media/movies:/media/movies

Read-only mounts fail at the swap step.

Path differs between hosts? Use TF_PATH_MAP:

TF_PATH_MAP='{"/media/movies":"/host/path"}'

S3 libraries

No shared filesystem needed — add to the run command:

-e TF_S3_ENDPOINT_URL=... -e TF_S3_REGION=... -e TF_S3_ACCESS_KEY_ID=... -e TF_S3_SECRET_ACCESS_KEY=... -e TF_SCRATCH_DIR=/scratch

For Docker, add -v /tmp/transcode-scratch:/scratch (or a faster SSD path).

Needs: Docker, or uv + Python 3.12 + ffmpeg · network reach to · a hardware encoder (QSV/NVENC) is optional — CPU works, slower.
