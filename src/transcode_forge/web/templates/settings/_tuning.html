Transcoding defaults

AV1 as the global default applies to every queue action. Older devices/clients may not decode AV1.

Target VMAF is below the perc5 safety floor. The search will aim for quality the gate refuses to keep, and encodes will be discarded after running in full. Raise the target or lower the floor.

Encoder priority QSV → NVENC → CPU
Max retries 3
Heartbeat 10s
Worker timeout 30s

Codec + VMAF save here; the rest via TF_* env vars.
